---
name: onboard
description: Set up a new person on this job-search pipeline from a fresh clone, then start searching and applying. Use when PROFILE is missing or names Example, when someone says they just cloned the repo, or asks how to start applying.
---

Follow `docs/onboarding.md` step by step, in order: machine check, profile folder, the profile interview, the base resume (sample format from their own resume, or a different style), passwords the user sets themselves, `jobs.py profile <Name>` and a Claude Code restart, then a supervised first batch of three applications before the full run.

Never write a fact into `profile.md` or `resume_base.tex` that the user did not give you or that is not in the resume they handed you. Never read or print `ATS-CREDENTIALS.txt`.
