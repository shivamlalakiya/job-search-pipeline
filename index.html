job-search-pipeline

Fewer, better job applications, sent for you.

A job search pipeline that applies only to roles you actually fit, tailors a one-page resume using only what you've already said is true, applies through the employer's own careers site, and then emails a real recruiter.

How it works Set up

How it works

Every application goes through five steps, and each step runs as its own short Claude Code session.

  1. ScoutSearches recent postings and drops the ones that fail a hard filter: clearance, licence, residency, pay floor, staffing agency, wrong profession.
  2. ResolveFollows each job-board link to the employer's own application page.
  3. TailorCuts your full base resume down to one page in LaTeX, plus a cover letter, both drawn only from your own record.
  4. ApplyA browser agent fills in the employer's application form and submits only when every answer came from your profile.
  5. OutreachFinds a recruiter by name and sends a short email with the tailored resume attached.

Built-in rules

Most auto-apply tools aim for volume. This one aims to send applications you'd be glad to sign.

Nothing made up

Every line on a resume, cover letter or form has to already exist in your base resume or profile. If a posting asks for a tool you haven't listed, you get a question, not a made-up bullet.

Stops when unsure

If the agent would have to make up an answer, it stops before submitting and records the exact question for you to answer.

Never applies twice

A tracker keeps every application. The same posting, the same role at the same company, or any company where you're already interviewing is skipped.

Your data stays on your machine

ATS passwords stay in a local file the browser types for you. They never appear in a prompt, a log or the repo.

Separate profiles

Several people can share one install. Each has their own folder, browser profile and credentials, and no fact crosses from one profile to another.

Applies on the employer's own site

Applies through the employer's own careers site instead of job-board quick-apply, including the systems that are hard to automate.

Applicant tracking systems

Notes on quirks, saved answers and page helpers, all built up from real applications.

Set up

macOS, Python 3.13 with openpyxl, Node 24, MacTeX and Claude Code with the Playwright MCP server.

cp -R profiles/Example profiles/YourName
cp profiles/YourName/ATS-CREDENTIALS.txt.example profiles/YourName/ATS-CREDENTIALS.txt
chmod 600 profiles/YourName/ATS-CREDENTIALS.txt
# edit base/resume_base.tex, profile.md, signature.txt, browser.txt
python3 jobs.py profile YourName      # then restart Claude Code
python3 jobs.py selfcheck
python3 scout.py "data analyst" --days 1 --track
python3 run_bulk.py --limit 5

Before you use it: automated access may break a job board's or ATS's terms of service. Read what the agents submit for you, because every application goes out under your name.
